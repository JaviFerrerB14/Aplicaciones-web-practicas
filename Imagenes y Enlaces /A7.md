# Que verá el usuario

A: La imagen del gato aparece a la derecha, y el texto la rodea por la izquierda. Es el efecto de float: right.

B: Si gato.jpg no existe, se muestra el texto alternativo “Gato durmiendo” (muchos navegadores añaden un icono de imagen rota).

C: Al hacer clic en el logo se abre la web del W3C en una pestaña nueva, por el target="_blank". Si logo.png no existe, verás el texto “W3C” como rótulo.
