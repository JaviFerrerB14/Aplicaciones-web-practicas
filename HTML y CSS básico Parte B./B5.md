        PARTE 3: reflexión
       ¿Qué significa rgb(0, 0, 255)?
       Son las cantidades de rojo, verde y azul (de 0 a 255):
       0 de rojo, 0 de verde y 255 (el máximo) de azul = azul puro.

       ¿Qué valor de hue corresponde en hsl a cada color?
       El hue (matiz) es un ángulo de 0 a 360 en la rueda de color:
       rojo = 0, verde = 120, azul = 240.
