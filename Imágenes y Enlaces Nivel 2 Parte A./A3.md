# Reflexiona

Es más útil en páginas largas: manuales, guías, preguntas frecuentes, documentación o textos legales.

Debe apuntar al id de la parte de arriba donde está el índice, por ejemplo href="#inicio". El enlace se escribe al final de cada sección.

El navegador saltaría solo a la primera de ellas, y el HTML sería inválido. Un id debe ser único.
